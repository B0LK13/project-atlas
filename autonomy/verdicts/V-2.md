**local branch literally named `origin/main`** was created pointing at a commit with no HALT
file, while the real `origin/main` (fetched into `refs/remotes/origin/main`) carried

`git rev-parse origin/main` in that clone printed
`warning: refname 'origin/main' is ambiguous.` and resolved to the **local** branch's commit
(no HALT) — proving a naive unqualified lookup would miss the HALT.

Calling the shipped code directly:
```
refreshed = preflight.refresh_grant_ref(root, "origin/main")
# -> "refs/remotes/origin/main"

# -> ["autonomy/HALT exists on refs/remotes/origin/main: the loop is stopped"]
```
PASS — HALT is correctly detected via the refreshed, unambiguous
`refs/remotes/<remote>/<branch>` ref despite the shadowing local branch.
