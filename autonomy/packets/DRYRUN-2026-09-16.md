## What this does not show

- It does not certify any head. Only CI plus an independent verifier can (policy section 4.4).
- Cert-before-packet ordering, forgery detection, the wall-clock and token budgets, and the
  green status of the four `lanes.required` checks remain unmechanized (policy section 12.3).
- The sandbox ran on one host (native Windows, Python 3.13). The Linux behaviour of the gate is
  covered by CI, not by this rehearsal.
- A sandbox grant proves the machinery reads a grant. It grants nothing: this repository still
  has no `autonomy/grants/G-1.md`.
