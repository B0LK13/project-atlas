# PROTOTYPE — Context assembly envelope

Status: **PROTOTYPE / PREP ONLY**.

## Purpose

Sketch context assembly for agents and UX: how retrieval, receipts, twin
snapshots, and governance constraints compose a bounded context window
without inventing estate facts.

## Design intents

- Prefer lexical/deterministic indexes before optional model assist
- Unknown ≠ healthy; absent evidence stays absent
- Context packs must carry provenance pointers

## Non-goals

- No production context API
- No automatic PILOT estate injection
- No OpenAI/MCP production wiring (see OPENAI-MCP-DESIGN.md)
