# Atlas 3.0 — Competitive positioning

## Category

Atlas 3 is not “another coding agent” and not “another chat memory plugin.”

It is the **verifiable shared reality layer** for a software project:

- evidence-backed
- time-aware
- conflict-honest
- provider-neutral
- non-authoritative until governed promotion

## Contrast

| Product class | Typical failure | Atlas 3 stance |
|---|---|---|
| Chatbot memory | Recency wins; no provenance | Conversation ≠ truth |
| IDE agent transcripts | Die with the session | Capture → quarantine → reconcile |
| RAG over a repo | Dumps context; hides conflicts | Budgeted Start; UNKNOWN stays UNKNOWN |
| Knowledge graphs | Edges become “truth” | Graph ≠ authority |
| Ticket/docs tools | Human-only; stale | Twin + pulse over landed evidence |
| Multi-model routers | Pick a model; forget the project | Models consume Atlas; they do not own it |

## Differentiation that must stay true

1. **Never explain twice** — Coder Alpha promise, kept.
2. **Never act on stale/conflicting/unproven/out-of-scope knowledge** — Atlas 3 extension.
3. **Provider neutrality** — ChatGPT, Claude, Gemini, Cursor, Codex are sources and consumers, not authorities.
4. **Owner decisions cannot be forged** from model paraphrase.
5. **Stronger project evidence outranks newer LLM text.**
6. **Proof-of-work is a chain**, not a checkbox the model ticks.
7. **Offline / local-first** remains the default.

## Claims we will not make

- Commercial GA
- Authentic PILOT from fixtures
- Full native history sync for Claude/Gemini
- Codex-validated security certification
- That UI or MCP is canonical truth
