# AS-2.0-INTEL-005 — Evidence Gap Detection

## Purpose

Identify missing evidence that would materially improve a derived
conclusion. Distinguish unknown-from-no-evidence, contested, and stale.

## Truth boundary

```
EVIDENCE GAP ≠ MISSING TRUTH / ≠ COMMAND TO INVENT EVIDENCE
UNKNOWN_FROM_NO_EVIDENCE ≠ CONTESTED
STALE ≠ INVALID
```
