# Support

## Who this repository is for today

Project Atlas is a **private**, pre-1.0 repository maintained by the
repository owner (`B0LK13`) and explicitly authorized agents. There is no
public product support desk, no community forum, and no guaranteed
response time.

## Boundaries

| Topic | Where to go |
| --- | --- |
| Security / vulnerability concerns | `SECURITY.md` — do **not** use ordinary public issues for sensitive details |
| Contribution workflow (authorized collaborators/agents) | `CONTRIBUTING.md`, `GOVERNANCE.md` |
| Conduct expectations | `CODE_OF_CONDUCT.md` |
| Version and release policy | `VERSIONING.md`, `RELEASING.md` |
| Product/architecture questions from authorized collaborators | Already-established private channel with the owner |

## What is not offered

- No public issue SLA, email alias, ticket portal, chatbot, or paging rota
  is published here.
- No external user support channel is claimed.
- Opening a GitHub issue (when issue forms exist) is for structured
  internal/authorized tracking only; it is not a promise of triage time.

## Deferred items

Any future public support surface (docs site, discussion board, external
intake address) requires separate Owner provisioning and must not be
invented in this file ahead of that provisioning.

See `SECURITY.md` for the security-reporting limitation and
`GOVERNANCE.md` for stop boundaries.
