# Event types

`session-start` is automatic. `implementation` records material file or behavior changes. `decision` records scope, architecture, compatibility, security, or data-policy decisions. `validation` records exact checks and outcomes. `blocked` records meaningful blockers or failures. `completion` records what finished, limitations, and pending work.

Every event is tied to the project, work package, agent, session, skill hash, source evidence, and route receipt by the pipeline.
