# Failure recovery

Capture failure: stop claiming documentation success, preserve project state, and retry only through the command surface.

Normalization or verification failure: do not route the derivative; retain raw evidence and correct the input or configuration.

Routing failure: retain verified evidence, do not edit Atlas pages, resolve identity or transaction conflicts, then retry.

Receipt failure: do not fabricate counts or receipts; add missing valid events and rerun strict validation.

Vault failure: use the approved spool only. Pending spool is incomplete under strict mode until synchronized.
