# Code of Conduct

## Our pledge

We pledge to make participation in Project Atlas a harassment-free
experience for everyone, regardless of age, body size, visible or
invisible disability, ethnicity, sex characteristics, gender identity and
expression, level of experience, education, socio-economic status,
nationality, personal appearance, race, caste, color, religion, or sexual
identity and orientation.

## Our standards

Examples of behavior that contributes to a positive environment:

- Demonstrating empathy and respect
- Giving and gracefully accepting constructive feedback
- Focusing on what is best for the project and its evidence integrity
- Showing courtesy in reviews, issues, and agent-session communications

Examples of unacceptable behavior:

- Harassment, trolling, insulting or derogatory comments
- Publishing others’ private information without explicit permission
- Sexualized language or imagery, or sexual attention of any kind
- Other conduct which could reasonably be considered inappropriate in a
  professional setting

This summary is aligned with the spirit of the Contributor Covenant
(v2.1). It is intentionally concise for a private, single-maintainer
repository.

## Scope

This Code applies within project spaces (issues, pull requests, and other
GitHub collaboration surfaces for this repository) and when an individual
is officially representing the project in related spaces authorized by the
owner.

## Enforcement (current limitation)

This repository is private and maintained by a single owner. There is
**no** published dedicated enforcement email, moderator team, or third-party
conduct portal, and none is invented here.

- Authorized collaborators should raise conduct concerns through an
  already-established private channel with the repository owner.
- Do not file ordinary public GitHub issues that contain private personal
  data about an incident.
- Security vulnerabilities are out of scope for this document; follow
  `SECURITY.md`.

The owner may remove, edit, or reject comments, commits, code, issues, and
other contributions that are not aligned with this Code, and may
temporarily or permanently ban any contributor for behaviors deemed
inappropriate, threatening, offensive, or harmful. No response-time
guarantee is offered.
